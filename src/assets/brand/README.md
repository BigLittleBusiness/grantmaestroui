# GrantMaestro Corporate Identity

This directory stores the user-supplied, canonical GrantMaestro identity assets and palette references. Do not replace, re-colour, crop or regenerate these source assets without approved replacement artwork.

## Logo treatments

| File | Use |
|---|---|
| `grantmaestro-logo-full-colour-transparent.png` | Full logo on white or other very light surfaces. |
| `grantmaestro-logo-white-transparent.png` | Full logo on navy or dark backgrounds. |
| `grantmaestro-logo-sky-transparent.png` | Full logo on navy where the lighter treatment is preferred. |
| `grantmaestro-icon-blue-on-white.webp` | Compact icon on light application surfaces. |
| `grantmaestro-icon-white-on-blue.webp` | PWA and app-icon treatment. |
| `grantmaestro-icon-white-on-navy.webp` | Compact icon on light surrounds or navy-brand collateral. |

## Core palette

- Bright blue `#2488FF`: primary action / active state (approximately 60% of brand colour use).
- Navy `#001A8B`: hierarchy, navigation and dark backgrounds (approximately 25%).
- Sky `#8FDAFA`: restrained highlights and contrast accents (approximately 15%).
- Supporting neutrals: white `#FFFFFF`, ink `#0D0D0D`, charcoal `#262626`, grey `#404040`.

The shared CSS tokens live in `src/assets/css/design-system.css`. Palette reference artwork is preserved in `palette/` for future design work.
